# Naming Rules

Use kebab-case for files:

```txt
module-a-table.tsx
module-a-form.tsx
module-a-queries.ts
use-module-a-form.ts
module-a-schema.ts
```

Use PascalCase for components:

```txt
ModuleATable
ModuleAForm
ModuleAPage
```

Use camelCase for functions:

```txt
getModuleA
createModuleA
updateModuleA
```

Use `*.types.ts` for types:

```txt
module-a.types.ts
```

Use `*.schema.ts` or `*-schema.ts` for validation schemas:

```txt
module-a-schema.ts
```
