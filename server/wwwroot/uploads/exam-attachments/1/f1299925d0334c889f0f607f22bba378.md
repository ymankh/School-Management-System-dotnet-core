## Brand & Style
The design system is engineered for high-utility educational environments, prioritizing clarity, trust, and efficiency. It adopts a **Corporate / Modern** aesthetic heavily influenced by Shadcn UI, characterized by a systematic approach to whitespace and structural integrity. 

The target audience includes administrators, educators, and students who require immediate access to complex data without cognitive overload. The UI evokes a sense of organized professionalism through a "Quiet UI" philosophy—where the interface recedes to let the data lead. Visual interest is achieved through precise geometry and a singular, purposeful accent color rather than decorative elements.

## Colors
This design system utilizes a sophisticated palette of **Indigo** and **Slate**. 

- **Primary (Indigo-600):** Used for actionable items, active states, and primary branding elements. It provides a confident, scholarly anchor to the interface.
- **Secondary/Neutral (Slate):** A range of cool grays used for text hierarchy, iconography, and subtle UI borders.
- **Backgrounds:** The interface relies on a tiered grayscale system. `Slate-50` is used for the main application background to reduce eye strain, while pure white (`#FFFFFF`) is reserved for cards and content containers to create a clear "layering" effect.
- **Status:** Standard semantic colors (Success: Emerald, Warning: Amber, Destructive: Rose) are used sparingly and always paired with high-contrast text for accessibility.

## Typography
The typography system uses **Inter** for all UI elements to ensure maximum legibility at small sizes, crucial for data-heavy tables and schedules. 

- **Headings:** Use a tighter letter-spacing and heavier weights to provide clear section anchoring.
- **Body Text:** The default size is 14px (`body-sm`) to allow for high information density while maintaining a comfortable line height of 1.4x.
- **Labels:** Use Medium (500) weight for buttons and navigation items to distinguish them from static content.
- **Monospace:** **JetBrains Mono** is introduced specifically for ID tags, student codes, and grade-point calculations to ensure character alignment in vertical lists.

## Layout & Spacing
The layout follows a **Fixed Grid** philosophy for desktop to maintain structural predictability in complex dashboards, and a fluid model for mobile.

- **Grid:** A 12-column system with a 24px (1.5rem) gutter. 
- **Sidebars:** A fixed-width left navigation (256px) is standard for administrative views.
- **Density:** To handle high-density information, the system uses "Compact" and "Standard" spacing modes. Compact mode (used in Data Tables) reduces vertical padding to 8px, while Standard mode (used in Settings/Profiles) uses 16px.
- **Margins:** Consistent 24px margins on all container edges ensure the content never feels cramped against the viewport.

## Elevation & Depth
In line with the Shadcn-inspired aesthetic, this design system moves away from heavy shadows in favor of **Low-contrast outlines** and **Tonal layers**.

- **Borders:** Surfaces are primarily defined by a 1px border (`Slate-200`). 
- **Depth:** Higher elevation is suggested through subtle, ambient shadows (e.g., `0 1px 3px 0 rgb(0 0 0 / 0.1)`). 
- **Active States:** Elements being dragged or modals use a medium shadow to indicate they are "floating" above the base grid. 
- **Hover:** Interactive cards use a very subtle background shift to `Slate-50` rather than an increased shadow to maintain the clean, flat look.

## Shapes
The shape language is disciplined and geometric. 

- **Rounded-md:** The standard for buttons, input fields, and cards is **0.25rem (4px)** to **0.375rem (6px)**. This "soft-square" look provides a professional, modern feel that is friendlier than sharp corners but more serious than pill shapes.
- **Interactive Elements:** Buttons and inputs share identical corner radii to ensure alignment when grouped in forms.
- **Data Indicators:** Status badges/chips may use a slightly higher radius (rounded-full) to distinguish them as discrete metadata.

## Components
- **Buttons:** Primary buttons use a solid Indigo-600 background with white text. Secondary buttons use a white background with a Slate-200 border. 
- **Input Fields:** Use a Slate-200 border that shifts to Indigo-600 on focus. Placeholder text is Slate-400.
- **Data Tables:** The core of the system. Feature a sticky header, zebra-striping (using Slate-50), and 12px horizontal padding. Borders are only used for horizontal separation.
- **Cards:** White background, 1px border (`Slate-200`), and no shadow unless the card is interactive.
- **Badges:** Small, low-saturation backgrounds with high-saturation text (e.g., a "Present" badge has a light emerald background with dark emerald text).
- **Navigation:** Vertical sidebar with icons. Active states are indicated by a subtle background fill and an Indigo-600 "pill" indicator on the left edge.
- **Schedules/Calendars:** Use a "Cell-based" layout with thin borders, ensuring text is vertically centered.
